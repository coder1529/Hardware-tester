    Browser quirks worth knowing
    • Camera and mic only work over https://, localhost or a file opened directly.
    • Safari keeps some F-keys and media keys for itself. They'll never reach the page.
    • On macOS, Caps Lock sends down when it turns on and up when it turns off. That's not a broken key.
    • Browsers hide gamepads until you press a button on one. Moving a stick isn't enough.
    • The Fn key never reaches a web page, on any OS.
